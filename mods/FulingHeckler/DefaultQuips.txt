# ============================================================================
#  Fuling Heckler: quips file
# ============================================================================
#  One line per quip:   event | when | text
#
#  event  What killed you. Most specific match wins, then it falls back:
#           enemy:<prefab> -> boss (bosses only) -> enemy -> generic
#           drowning, fall, burning, freezing, poison, smoke, edge, boiled,
#           tree, stalactite, lava, incinerator, self, friend, cart, boat, structural, siege,
#           unknown -> generic
#         flee = what he shouts when you walk up too close and he runs off
#         spotted, bored, boo, tombstone, copycat_bye, copycat_rude, campfire,
#         thief_steal, thief_oops, thief_fee, thief_nope,
#         gift_junk, gift_nice, gift_treasure, gift_caught = lines for the scenes
#         Creature prefab names: https://valheim-modding.github.io/Jotunn/data/prefabs/character-list.html
#
#  when   first      the first time you die this way
#         repeat     any time after that
#         milestone  death number 5, 10, 25... (set in config)
#         any        always eligible
#
#  Placeholders:
#         {name}    your character's name
#         {killer}  what killed you ("Troll", or a friend's name)
#         {count}   "2nd", "3rd", ... "27th"
#         {n}       the plain number
#         {me}      his name, or just "Fuling" (by chance: 'Say His Name Chance'
#                   in F1 > 3 - Look). Plain "Fuling" always stays "Fuling",
#                   good for goblins in general: "Fuling village".
#
#  Edit freely, then press "Reload quips file" in the config menu (F1).
#  Delete this file to get the defaults back.
# ============================================================================
