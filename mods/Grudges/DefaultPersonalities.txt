# Grudges: personalities.
#
# Every new nemesis gets one at random (by weight). Edit freely; new sections become new personalities.
#
# Keys (all optional):
#   weight      how often it's picked compared with the others (1 = normal, 0 = never)
#   size        nudges its size within the size range: -1 = smallest, 0 = no nudge, 1 = biggest
#   palettes    colourings it leans toward (names from 'Palettes' in the config)
#   prop        what it carries: item:<ItemName>@<Bone>  (bones: Head, Chest, UpperChest, Spine, Hips,
#               LeftShoulder, RightShoulder, LeftHand, RightHand). Placement is set with the fitting tool.
#   emotes-new-killer, emotes-witness, emotes-killed-again, emotes-saw-again, emotes-returned, emotes-on-sight
#               player emotes for each moment (part of the name is enough; the log line 'Player animations'
#               lists them). Anything left out uses the settings in F1.
#   animations  its own animation triggers, for creatures that can't do player emotes (e.g. jump, stagger)
#
# A section named [Personality:Creature], e.g. [Brute:Fuling], overrides any key for that creature type only.
#
# Lines: in the lines file, a section like [taunt-killer/Braggart] is used for that personality
# (most of the time), with the normal [taunt-killer] as the fallback.
#
# [Default] is not a personality: it's what every personality falls back to for anything it doesn't set.
