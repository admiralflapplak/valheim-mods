# Grudges: every line the mod says.
#
# Edit freely. Lines are picked at random from a [section].
# A section can be made specific to a creature or a cause, e.g. [prefix:Greydwarf] or [taunt-witness:Tree].
# The specific one is used when it exists; otherwise the general one ([prefix], [taunt-witness]).
#
# Placeholders:
#   {player}  the player's name
#   {name}    the nemesis's full name, e.g. "Mossjaw the Rot-Tongued"
#   {short}   just the name, e.g. "Mossjaw"
#   {species} e.g. "Greydwarf"
#   {kills}   how many times it has killed this player (a number)
#   {times}   the same in words: "once", "twice", "4 times"
#   {cause}   what killed the player in a witnessed death: "a tree", "the ground", "a boar"
#   {other}   another nemesis (used in challenge messages)
#
# Cause keys for specific sections: Tree, Fall, Drowning, Burning, Freezing, Poisoned, Smoke, Boiled,
# Self, Friend, Cart, Boat, Creature, Other
